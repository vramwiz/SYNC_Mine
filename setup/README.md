# MINE（SYNC_MINE）

スマホ本体とLINE風の会話画面を描画するAviUtl2用フィルタプラグインです。メッセージや写真を並べ、「段階」を動かして入力・送受信・既読のアニメーションを作れます。

## インストール・更新

1. AviUtl2を終了します。
2. `SYNC_MINE.zip` を展開し、中の `SYNC_MINE` フォルダーをAviUtl2の `Plugin` フォルダーへコピーします。通常の配置先は `C:\ProgramData\aviutl2\Plugin\SYNC_MINE` です。
3. AviUtl2を起動し、オブジェクトに「SYNC」グループの「MINE」を追加します。

更新する場合も同じ場所へ上書きします。ZIPにはプラグイン本体・このREADME・ライセンス類を収録しています。キャラ生成用リソースはプラグインへ埋め込み済みです。

## 会話を作る

1. フィルタの「設定」を開きます。
2. 「アイコン」でキャラ名を入力、または候補から選び、自分側／相手側を設定します。任意の画像ファイルも参照でき、倍率・X・Y補正で円形枠に合わせられます。枠の下のピッカーでアイコン背景色を変更します。
3. 「メッセージ」の本文に入力します。Enterで次の発言を追加し、同じキャラで続けて入力できます。「写真」の参照から、写真のみ・本文付きの写真メッセージを作れます。
4. 「設定」ページでトーク名とスマホの縦／横向きを選びます。「背景・文字色・自分・相手・スマホ」を切り替え、下のカラーピッカーで配色を変更します。自分・相手は吹き出しの背景色、スマホは本体色です。
5. 右側の段階スライダーで確認し、「閉じる」またはタイトルバーの×で保存します。
6. AviUtl2側でX・Y・拡大率・透明度を調整し、「段階」をイージングで動かします。

本文の文字色は吹き出しの背景色から黒・白を自動選択します。「文字色」で指定する色は名前・時刻・既読に適用します。

## 段階

| 段階 | 表示 |
| --- | --- |
| 0 | 会話なし |
| 1〜99 | 1件目のアニメーション |
| 100 | 1件目が既読 |
| 101〜199 | 2件目のアニメーション |
| 200 | 2件目が既読 |

以降も1件につき100段階です。写真も同じです。自分側は入力欄で文字を打ってから送信し、相手側は吹き出しが現れます。時刻と既読は吹き出しの下に表示します。段階と透明度の変更単位は1です。

## キーボード・一覧操作

| 操作 | 動作 |
| --- | --- |
| Enter | 次の発言を追加して入力を継続 |
| Shift+Enter | 本文内で改行 |
| Ctrl+1〜9 | 一覧順のキャラへ変更。テンキーにも対応 |
| Ctrl+↑／Ctrl+↓ | 前後の発言へ移動 |
| Backspace | 空の本文で押すと、写真のない発言を削除して前へ移動 |
| Delete | 本文の文字を削除。空になっても行は残す |
| Ctrl+Z | 削除直後は発言を復元。通常の入力中は文字を取り消し |
| Ctrlクリック／Shiftクリック | 一覧で個別／範囲の複数選択 |
| ドラッグ＆ドロップ | 選択した発言をまとめて移動。緑のラインが挿入先 |

日本語変換を確定するEnterでは発言を追加しません。発言者の候補やCtrl+1〜9による変更は、複数選択した発言すべてに適用します。複数選択中の本文は読み取り専用で、Enterを押すと1件の編集へ戻ります。本文を消し切っても行は残し、空の状態で改めてBackspaceを押すと削除します。写真付きの発言は空の本文でBackspaceを押しても残り、空行もそのまま保存します。

## 保存する内容

- 会話・配色・写真やアイコンの参照は、AviUtl2のオブジェクトに保存します。
- キャラ名の履歴とアイコン補正・背景色は、マイドキュメントの `SYNC_MINE\characters.json` に保存します。最近使った名前から再利用できます。
- 生成したキャラPNGは、マイドキュメントの `SYNC_MINE\Icons` 配下に保存します。
- 指定した画像と写真はファイル参照です。素材を移動した場合は参照先を選び直してください。

アンインストールする場合はAviUtl2を終了し、インストール先の `SYNC_MINE.auf2` と同梱のREADME・ライセンス類を削除します。マイドキュメントの設定・生成画像と、利用者が用意した素材は別に保存されています。

## 配布ZIPの作成・カタログ登録

以下は開発用プロジェクトでの手順です。

1. Win64のReleaseをビルドします。配布バッチは `Win64\Release\SYNC_MINE.auf2` を使用します。
2. `xxhsum.exe` を `Win64\Dependencies\xxHash-0.8.4` またはPATHの通った場所へ配置します。
3. `setup\SYNC_MINE.catalog.json` の `version` 末尾に、公開するタグと日付を設定します。次の版は末尾に追加します。
4. `setup\make_release_zip.bat` を実行します。`setup\SYNC_MINE.zip` を作成し、収録したAUF2の `XXH3_128` をJSONの末尾バージョンへ記録します。
5. GitHub Releaseへ `SYNC_MINE.zip` を添付し、カタログ登録用に `SYNC_MINE.catalog.json` を使用します。

公開先の初期設定は `vramwiz/SYNC_MINE` です。別のリポジトリで公開する場合は、JSONの `repoURL`・`description`・`installer.source.github` を合わせて変更してください。公開操作はバッチでは行いません。

別のRelease出力先やxxhsumを使用する場合は、次のように指定できます。

```powershell
.\setup\make_release_zip.bat -ReleaseDirectory "D:\Release" -XxhsumPath "D:\Tools\xxhsum.exe"
```
