# MINE（SYNC_MINE）

LINE風の会話画面をスマホ本体ごと描画する AviUtl2 用フィルタープラグインです。

## 使い方

1. オブジェクトに「SYNC」グループの「MINE」を追加します。スマホ全体を置く場合は、画面サイズのオブジェクトを使います。
2. 「設定」→「アイコン」でキャラ名を入力、または候補から選択します。候補の上には最近使った名前が並び、その下に既存のキャラ名が続きます。履歴から選ぶとアイコンの参照先・拡大率・X・Y補正・背景色も戻ります。既存キャラならアイコンを生成できます。自分側／相手側と、参照する画像もここで設定します。背景色はアイコン枠の下に常時表示されるカラーピッカーで直接変更します。
3. 「メッセージ」では左に発言一覧、右に本文と発言者・時刻・写真を表示します。開いたらそのまま本文を入力でき、Enterで直後へ次の発言を追加します。発言者は直前と同じです。発言者や写真などは後からマウスで調整できます。写真だけ、または本文と写真の組み合わせに対応します。
4. 一番右の「設定」の先頭行でトーク名とスマホの方向を編集します。その下の「背景」「文字色」「自分」「相手」「スマホ」から配色対象を選び、共通のカラーピッカーで直接変更します。「自分」「相手」は吹き出しの背景色、「スマホ」は本体色です。方向と本体色はAviUtl2側の同名パラメータにも反映します。
5. 右側の段階スライダーで、入力・送受信・既読の動きを確認します。「閉じる」またはタイトルバーの×で変更を保存して終了します。X・Y・拡大率・透明度はAviUtl2側で調整します。
6. 「段階」を AviUtl2 のイージングで変化させて会話を進めます。

| 段階 | 表示 |
| --- | --- |
| 0 | 会話なし。スマホ本体と空のトーク画面 |
| 1～99 | 1件目のアニメーション |
| 100 | 1件目が既読 |
| 101～199 | 2件目のアニメーション |
| 200 | 2件目が既読 |

以降も1件につき100段階です。写真も同じです。相手側はアイコン付きの左寄せ、自分側は右寄せの吹き出しで表示します。自分側は最初の85段階で入力欄に文字を打ち、残りの段階で送信します。99で送受信の表示が完了し、100で既読になります。時刻と既読は吹き出しの下に表示します。スクロールも段階から計算するので、逆再生や途中への移動でも同じ結果になります。

吹き出し内の本文は、各吹き出しの背景色から見やすい黒・白を自動で選びます。「文字色」の設定は名前・時刻・既読に適用します。配色は会話データとともにオブジェクトへ保存します。

アイコンと写真はファイル参照です。素材を移動した場合は参照先を選び直してください。

メッセージ入力のキー操作は次のとおりです。

| キー | 操作 |
| --- | --- |
| Enter | 今の発言の直後に次の発言を追加し、入力を継続 |
| Shift+Enter | 本文内を改行 |
| Ctrl+1〜9 | 一覧順の発言者を選択。複数選択中は選択した発言すべてへ適用。テンキーにも対応 |
| Ctrl+↑ / Ctrl+↓ | 前後の発言へ移動 |
| Backspace | 空の本文で押すと発言を削除して前へ移動。文字を消し切った時点では行を残す |
| Delete | 本文の文字を削除。空になっても発言は残す |
| Ctrl+Z | 発言削除の直後は削除した発言を復元。通常の本文入力中は文字の取り消し |

日本語変換を確定するEnterでは次の発言を追加しません。本文を消し切っても行は残り、空の状態で改めてBackspaceを押すと発言を削除します。写真付きの発言は空の本文でBackspaceを押しても残します。空行もそのまま保存します。発言者の候補には番号を表示し、Ctrl+1〜9で現在の発言者を切り替えます。次の発言も選んだキャラを引き継ぎます。存在しない番号では変更しません。一覧にフォーカスがある場合もCtrl+1〜9が使え、1件選択中なら本文へ、複数選択中なら一覧へフォーカスを移します。上下で選択、Enterで1件の本文編集へ戻れます。1件選択中はInsertで追加、Delete・Backspaceで発言削除、Alt+↑↓で並べ替えができます。

一覧はCtrlクリックで個別に、Shiftクリックで範囲を複数選択できます。「発言者」の候補またはCtrl+1〜9で、選択した発言すべてのキャラをまとめて変更します。変更後も複数選択を保ちます。複数選択中の本文は読み取り専用で、Enterを押すと1件の編集に戻ります。

一覧の行はドラッグ＆ドロップで並べ替えられます。選択した複数の発言も、その順序を保って一緒に移動します。ドラッグ中は緑色のラインで挿入位置を表示し、一覧の上下端では自動スクロールします。

キャラ名の履歴とアイコン設定は、設定画面を閉じるとマイドキュメントの `SYNC_MINE\characters.json` へ保存し、次回も使えます。名前は最近使った順に並び、重複した名前は先頭へ移動します。自分側／相手側は会話ごとの設定です。会話本文と写真の参照は引き続きAviUtl2のオブジェクトに保存します。

キャラ名から生成したPNGも、マイドキュメントの `SYNC_MINE\Icons` 配下に保存します。透明情報を保つ生成版を使用し、過去の生成PNGも残します。生成済みPNGが見つからない場合は、埋め込みリソースから再生成します。

アイコン枠の下の色相バーと正方形の彩度・明度エリアを操作すると、背景色がその場でプレビューへ反映されます。設定ページでも、本体色を含むすべての配色を常時表示のピッカーで編集できます。選択色の見本と色コード `#RRGGBB` も表示します。

設定画面はWindowsの表示倍率に合わせて文字と部品を拡大します。ページ切り替え・スライダー・操作ボタンは暗色です。アイコンと設定ページはスクロールせず操作できるように配置し、メッセージ編集だけは必要に応じてスクロールできます。

## ビルド

Delphi 37.0 で `SYNC_MINE.dproj` を開き、Win64 の Debug または Release をビルドします。コピー元のビルド後イベントにより `.auf2` を作成し、`C:\ProgramData\aviutl2\Plugin\SYNC_MINE\SYNC_MINE.auf2` へ配置します。起動中の AviUtl2 では再起動して読み込みます。

キャラアイコンには、`..\AviUtl2Plugin\AviUtl2PluginLib` の VectorRenderer・RTTI保存基盤と `Serif\Chara\SerifCharaVectorResource.RES` を相対参照で再利用します。実行時のキャラデータはプラグインに埋め込みます。

配布ZIPは `setup\make_release_zip.bat` で作成します。`Win64\Release\SYNC_MINE.auf2` と利用者向けREADME・ライセンスを収録し、`setup\SYNC_MINE.catalog.json` の末尾バージョンへXXH3-128を記録します。詳しくは [配布用README](setup/README.md) を参照してください。
